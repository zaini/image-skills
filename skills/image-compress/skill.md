name: image-compress
description: Compress an image's file size by resizing and/or re-encoding it (to WebP, JPEG, or optimized PNG) using Pillow. Use when the user asks to compress, shrink, optimize, or reduce the file size of an image — including images just generated by the gpt-image or gemini-image skills.
---

Shrink an image's file size via the bundled script (`scripts/compress_image.py`).

## Requirements

- Pillow: `pip install Pillow` (not in the standard library — this is the one skill in
  this repo with a dependency, since real compression needs a real codec library).

## Process

1. **Pick a format** — default to `webp` (best size/quality tradeoff for most images).
   Use `jpeg` for maximum compatibility, or `png` if the source has transparency you must
   keep in a lossless-ish format (PNG "quality" here only controls palette size, not true
   lossless-vs-lossy).

2. **Pick a quality** — default `80`. Go lower (`50-65`) for "make it as small as
   possible" / thumbnails; higher (`85-95`) for "barely notice the difference".

3. **Pick a max dimension (optional)** — resizing is the biggest lever for file size.
   If the user doesn't need full resolution (web use, thumbnails, previews), pass
   `--max-dimension` to downscale the longer edge before re-encoding.

4. **Run:**
   ```bash
   python3 ~/.claude/skills/image-compress/scripts/compress_image.py \
     --input <path> [path2 path3 ...] \
     [--format webp] [--quality 80] [--max-dimension 1600] \
     [--strip-metadata] [--output <path> | --output-dir <dir>]
   ```
   - Single input: `--output` sets an exact output path (defaults to
     `<name>_compressed.<ext>` next to the input).
   - Multiple inputs: use `--output-dir` (defaults to each input's own directory) —
     `--output` is rejected with more than one `--input`.
   - The script prints before/after size and percent reduction per file, and a total
     when compressing more than one.

5. **Report the result** — tell the user the size reduction (the script's own stdout
   has it) and where the compressed file(s) landed.

6. **If it's still too big** — lower `--quality` further, add/lower `--max-dimension`,
   or switch `--format webp` (usually smallest) before trying anything more exotic.

## Examples

```bash
# Default: WebP, quality 80, no resize
python3 ~/.claude/skills/image-compress/scripts/compress_image.py --input photo.png

# Aggressive compression for a thumbnail
python3 ~/.claude/skills/image-compress/scripts/compress_image.py \
  --input hero.png --format webp --quality 55 --max-dimension 800

# JPEG for max compatibility, explicit output path
python3 ~/.claude/skills/image-compress/scripts/compress_image.py \
  --input banner.png --format jpeg --quality 75 --output banner-small.jpg

# Batch-compress a folder's worth of screenshots into another directory
python3 ~/.claude/skills/image-compress/scripts/compress_image.py \
  --input screenshots/*.png --format webp --quality 80 --output-dir compressed/

# Strip EXIF/ICC metadata too (privacy + a little extra size)
python3 ~/.claude/skills/image-compress/scripts/compress_image.py \
  --input selfie.jpg --strip-metadata
```
