---
name: background-remove
description: Remove the background from an image locally using rembg — outputs a transparent PNG/WebP cutout, a solid-colour fill, or a black/white mask. No API key needed. Use when the user asks to remove, cut out, erase, or make transparent the background of an image, or wants a subject cutout, sticker, product shot, or mask — including images just generated by the gpt-image or gemini-image skills.
---

Remove an image's background via the bundled script (`scripts/remove_background.py`). It
runs entirely on the user's machine (rembg + ONNX Runtime on CPU) — no API key, no upload.

## Requirements

- Python 3.11–3.13 and [rembg](https://github.com/danielgatis/rembg) (`rembg[cpu]`).
- **Easiest:** run the script with `uv run` — the dependencies are declared in the script's
  header, so `uv` installs them into an isolated cached environment automatically.
- **Without uv:** `pip install "rembg[cpu]"`, then run with `python3` instead of `uv run`.
- The segmentation model downloads on first use to `~/.rembg/models/` (override with the
  `REMBG_HOME` env var) and is cached after that.

**The very first run is slow** — dependency install plus a model download (hundreds of MB)
took ~7 minutes on a first test. Tell the user that's why, and pass a long Bash timeout
(e.g. `600000` ms). Later runs take a few seconds per image.

## Process

1. **Pick a model** — default `birefnet-general-lite`; in a side-by-side test its cutout
   was nearly indistinguishable from the full BiRefNet's, at a quarter of the download.
   Sizes/speeds below are approximate (Apple-silicon CPU, images up to ~1000px):

   | Model | Download | Time/image | Use for |
   |---|---|---|---|
   | `birefnet-general-lite` (default) | ~225 MB | ~5–10 s | almost everything |
   | `birefnet-general` | ~930 MB | ~10–12 s | maximum quality, fine detail |
   | `birefnet-portrait` | ~930 MB | ~10 s | photos of people |
   | `isnet-general-use` | ~180 MB | ~1 s | fast and still good |
   | `silueta` | ~45 MB | <1 s | tiny/fastest; edges are noticeably rougher |

2. **Pick the output style:**
   - Default — transparent PNG (`<name>_nobg.png` next to the input).
   - `--bgcolor <colour>` — fill with a solid colour instead (`white`, `'#ff8800'`, …).
     Required if you want a `.jpg` output, since JPEG can't hold transparency.
   - `--only-mask` — output the black/white cutout mask (`<name>_mask.png`) instead.

3. **Run:**
   ```bash
   uv run ~/.claude/skills/background-remove/scripts/remove_background.py \
     --input <path> [path2 path3 ...] \
     [--model birefnet-general-lite] [--alpha-matting] \
     [--bgcolor <colour> | --only-mask] \
     [--output <path> | --output-dir <dir>]
   ```
   - Single input: `--output` sets an exact output path (`.png`, `.webp`, or `.jpg`).
   - Multiple inputs: use `--output-dir` (defaults to each input's own directory) —
     `--output` is rejected with more than one `--input`. The model loads once for the
     whole batch.
   - The script prints each output path with its processing time. EXIF rotation from
     phone photos is applied automatically.

4. **Check the result** — Read the output image before reporting back. Transparent areas
   can render as black or white in a viewer, so to judge edges, re-run with a contrasting
   `--bgcolor` into a scratch path.

5. **If the edges are rough** — try `--model birefnet-general` first, then add
   `--alpha-matting` (refines soft edges like hair and fur; results vary, so compare).

6. **If the file is too big** — cutouts are usually PNGs; shrink them with the
   `image-compress` skill using `--format webp`, which keeps the transparency (a test
   cutout went 108 KB → 19 KB). Don't use `--format jpeg` there — it drops the alpha
   channel.

## Limitations

- **Images only** — no video or GIF.
- **It keeps every salient subject.** There's no way to say "only the car": in a test photo
  with a car and a pedestrian, both were kept. Crop the input first if you need one subject.
- The smaller models (`silueta`, `isnet-general-use`) can leave rougher edges or faint
  halos around the subject; step up to a BiRefNet model if that shows.

## Examples

```bash
# Default: transparent PNG next to the input (photo_nobg.png)
uv run ~/.claude/skills/background-remove/scripts/remove_background.py --input photo.jpg

# Product shot on a white background, saved as JPEG
uv run ~/.claude/skills/background-remove/scripts/remove_background.py \
  --input product.png --bgcolor white --output product-white.jpg

# Portrait with the people-tuned model and edge refinement
uv run ~/.claude/skills/background-remove/scripts/remove_background.py \
  --input headshot.jpg --model birefnet-portrait --alpha-matting

# Batch a folder of images into another directory, fast model
uv run ~/.claude/skills/background-remove/scripts/remove_background.py \
  --input shots/*.jpg --model isnet-general-use --output-dir cutouts/

# Just the mask (photo_mask.png)
uv run ~/.claude/skills/background-remove/scripts/remove_background.py \
  --input photo.jpg --only-mask

# Same thing without uv, after `pip install "rembg[cpu]"`
python3 ~/.claude/skills/background-remove/scripts/remove_background.py --input photo.jpg
```
